[ why hotwash ]

Most ranges do one thing. This one fights back.

Jeopardy platforms hand every team the same flag. Cyber ranges run a canned adversary against you. Hotwash seeds a different, verified instance per team, grades blue as rigorously as red, and puts both cells in the same live match — then writes the debrief.

// seeded & verified

Uncopyable, never broken

Each team’s seed produces its own artifacts and flags, and an independent solver recovers every flag before an instance is served. Leaks are worthless and traceable; 2 a.m. “the flag’s broken” messages don’t happen.

// live red // blue

Outcomes, not keystrokes

A mediation plane sits between both cells and scores what they actually achieve — a seeded proof you can’t read without real compromise, real detections, real eviction, real uptime. Not scripted buttons.

// the payoff

Every fight ends in a hotwash

The after-action report writes itself from the engagement journal: five hotwash questions, per-operator scorecards, the timeline, and a prioritized fix plan with an owner for each gap.
