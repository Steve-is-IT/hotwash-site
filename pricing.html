// licensing & deployment

The honest answers.

Why no price on the page?

Hotwash is a licensed platform sold like a security product, not a self-serve SaaS. Scope depends on cohort size, whether you need live sandboxed or container-backed targets, and support level — so we size it with you rather than printing a number that would be wrong for most of you.

Does every tier run offline / air-gapped?

Yes. Targets, consoles and scoring run air-gapped on all tiers; challenge content ships as signed offline bundles, and nothing is pulled from the internet at match time. The Digital-twin tier is designed to stand up inside an isolated range network.

Do all tiers grade the same way?

Yes. Grading is server-side on the mediation plane for every tier, so a result on the Console tier means the same thing as the same result on the Digital-twin tier. Moving up a tier changes reach and realism, never the scoring.

Is there an education discount?

The Community / Education tier is the free core for schools and training providers — per-student seeded variants, LTI rostering and offline operation. Request access and tell us about your cohort.

Can we author and run our own scenarios?

Yes — a documented DSL and authoring guide ship on every tier, and the engine validates and verifies every scenario (the independent solver must recover every flag) before it can be served.
