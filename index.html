// two guarantees

Leaked flags are worthless. Broken challenges don't ship.

01

Uncopyable flags

Every flag is derived from the team's seed. Paste it into another team's box and it's just wrong — and the submission log points straight back to whoever leaked it.

flag = HMAC(seed, challenge) # different for every team
02

Never-broken challenges

Before any instance is served, an independent solver re-solves it headlessly. If it can't recover the flag, the instance is regenerated or pulled. Nothing reaches a player unverified.

[verify] fresh-catch: solver recovered primary ✓

// the main event

Live attack & defend

Red recons, exploits, harvests credentials, pivots, escalates and goes for the objective on a seeded network. Every move throws off telemetry.

A behaviour-analytics layer turns that telemetry into alerts. Blue works the queue and hits back — isolate a host, kill a session, disable an account, patch a service. Cut red's active path and that's a point for defense. Red adapts, or gets contained before the clock runs out.

// the loop

Author once. Everyone fights a different fight.

01 · AUTHOR

Write it once

One challenge template in YAML — artifacts, flags, a solver, a live target.

02 · SEED

Per-team variant

Each team's seed produces its own hosts, creds and flags.

03 · VERIFY

Fresh catch

An independent solver proves every instance before release.

04 · PLAY

Attack & defend

Jeopardy, detection rules, or a live red/blue engagement.

05 · HOTWASH

Debrief

An automatic after-action report with a prioritized fix plan.

// arsenal

Built for the whole fight.

[ red ]

Live targets

Seeded, sandboxed, loopback-only vulnerable apps. Real exploitation, isolated per team.

[ blue ]

Detection engineering

Write a Sigma or YARA rule; it's graded on planted malicious + benign data. Pass with no false positives.

[ purple ]

Dual-face incidents

One incident, two sides — red exploits it, blue detects it from the telemetry the exploit produced.

[ sys ]

Offline & air-gapped

Runs with the cable unplugged. Signed offline content bundles, no pulls at play time.

[ edu ]

Classroom / LTI 1.3

Rostered teams, graded challenges, scores posted back to the gradebook.

[ aar ]

After-action reports

NCL-style scouting reports and a facilitated hotwash with an owned, prioritized remediation plan.
