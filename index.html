// the integrity contract

Leaked flags are worthless. Broken challenges don’t ship.

01

Uncopyable flags

Every flag is derived from the team’s seed. Paste it into another team’s box and it’s just wrong — and the submission log points straight back to whoever leaked it.

flag = HMAC(seed, challenge) # different for every team

02

Never-broken challenges

Before any instance is served, an independent solver re-solves it headlessly. If it can’t recover the flag, the instance is regenerated or pulled. Nothing reaches a player unverified.

[verify] fresh-catch: solver recovered primary ✓

✓ Seeded determinism — same input, same artifacts ✓ Server-side grading — the key never reaches a player ✓ Offline / air-gapped — nothing pulled at match time

// the rule

Gate outcomes, not keystrokes.

No points for an exploit that merely fires. Red scores only by recovering the seeded proof from the box it was planted on — and holding it. Blue scores by detecting, containing and keeping services answering. Running a tool proves nothing — surviving on the box, and evicting whoever is already on it, is the whole game.

Red scores on real compromise

Points exist only as seeded secrets you can’t read without genuine compromise — and capture means hold, not touch: a dwell timer makes you survive on the box while blue tries to evict.

✓ proof recovered from dc01 · dwell 90s held

Blue scores on real defense

Points for detecting the move, containing the active path, and keeping graded services available — minus the disruption cost of heavy-handed responses that take your own network down.

✓ lateral path cut · app01 isolated · SLA held

The mediation plane. Both cells act on one seeded network through a mediation layer. A data plane — a segmentation gateway every flow crosses, plus host sensors reading ground truth — feeds one correlated stream to both sides at once. A control-plane referee holds the prerequisite graph, dwell timers, proof grading and the uptime/disruption ledger over an immutable journal. The score is ground truth, not either side’s claim.

// questions

The short version.

What does “uncopyable” actually mean?

Each team’s flag is derived from its own seed, so a flag that’s correct for one team is wrong for every other team. Share it and it fails — and the server-side log ties the attempt back to the team it belongs to.

Is the live attack-and-defend real exploitation?

Both sides use real tools against real, sandboxed infrastructure, and Hotwash grades observed outcomes — a seeded proof you can’t read without genuine compromise, real detections, real eviction, real availability. Not scripted buttons. Everything is isolated per team and torn down after.

Do defenders just click our buttons?

No. In the own-kit tier blue works from its own tools against real infrastructure with a live telemetry feed into its own SIEM; the platform grades availability, flag retention, real detections and real eviction. The console is optional scaffolding.

Does it work offline / air-gapped?

Yes. Targets, consoles and scoring run air-gapped; challenge content ships as signed offline bundles, and nothing is pulled at play time.

How is a detection-engineering challenge graded?

You submit a Sigma, YARA or Suricata-style rule. It’s run server-side against the challenge’s planted malicious data and its benign noise; you pass by catching the plant with no false positives.

How is it fair across a whole cohort?

Every team gets a different seeded variant of the same scenario, and an independent solver verifies each instance before it’s served. Grading is server-side, so the answer key never reaches a player.

Can we author our own scenarios?

Yes — there’s a documented DSL and authoring guide, and the engine validates and verifies every scenario before it can be served.
