[ get hotwash running ]

Request access. Install. Serve a range.

Hotwash is the hotwash Python package — offline-first, one process, no internet at match time. It is a licensed product rather than a public download, so “get Hotwash” means request access, then install. Once you have the bundle, a live red-vs-blue arena is one command away.

Python 3.11+One processOffline / air-gappedZero player setup

// from zero to a live arena

Three steps to the first match.

01

Get access & the offline bundle

Hotwash ships as a signed offline package with its content bundles — not from public PyPI. Request access and you receive the hotwash wheel plus the scenario bundles for your tier.

02

Install into a virtualenv

Create a Python 3.11+ virtualenv and install the package you were given. Nothing phones home.

$ python -m venv .venv
$ . .venv/bin/activate
$ pip install hotwash          # from your access bundle / private index
$ hotwash arena list            # confirm the install + list seeded scenarios
03

Serve an arena in one command

The console tier runs the whole arena — red/blue consoles, the observer attack map, the organizer controls and the hotwash report — from a single process. Open a pre-game loadout draft with --draft-budget.

$ hotwash arena serve --scenario crossfire --draft-budget 200

For the own-kit / digital-twin tier, back the objectives with real isolated containers from an offline bundle dir — the same command, a different backend:

$ hotwash arena serve --scenario crossfire \
    --backend container --bundle-dir /opt/hotwash/images --port 8095

// what it prints

It hands you the links and tokens.

On start, the server prints the lobby URL, the per-role console links with their tokens, the observer-board URL, and the organizer token. Hand each side its link; put the observer board on the projector.

lobbyhttp://localhost:8095/arena/<id>
red consolehttp://localhost:8095/arena/<id>/red?token=…
blue consolehttp://localhost:8095/arena/<id>/blue?token=…
observerhttp://localhost:8095/arena/<id>/observer
organizertoken · opens prep / begin / inject controls

⚑ run it hostile. Run the server behind your range’s own reverse proxy / TLS for anything beyond localhost, and keep every target sandboxed — isolated network, resource-capped, ephemeral. Nothing is pulled from the internet at match time, and the answer key never leaves the server.

// the match flow

Draft → prep → live → hotwash.

01 · DRAFT

Spend the budget

With a draft budget, each cell drafts its loadout of real capabilities in its console.

02 · PREP

Open prep

The organizer calls Open prep; teams deploy and harden — the availability checker is already running.

03 · LIVE

Begin match

Begin the match. Red works the kill chain, blue detects and contains, the white cell fires injects.

04 · HOTWASH

Debrief

At the clock, the journal becomes a facilitated after-action report with a per-operator scorecard.

hotwash arena list --tick-seconds <n> --duration-ticks <n> --live GET /arenas/<id>/report.html
